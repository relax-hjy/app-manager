## 决策日志
- **2026-10-13**：文档工作流严格对齐《项目文档初始化模板》：任务标识 🚧 改为 [正在做]，「停车场」并入「待办列表」按优先级排序（原 #2 数据库备份/导出 转为 P2 条目），「更新文档」与「本轮完成」统一为同一收尾流程；原因是模板是文档体系的唯一基准
- **2026-10-12**：集群化部署定为「中心服务（容器化到 WSL kind）+ 本地执行代理 win-agent」两层架构，原生 Windows 能力收敛到 Agent 执行、中心只下发意图命令；否决 Windows 容器方案（镜像巨大且 Linux kind 集群不支持）。Agent 采用用户登录自启 + 托盘而非 Windows 服务，原因是 Session 0 无桌面、GUI 启动对用户不可见。多套 Windows 原生项目共用同一 Agent，命令集走白名单
- **2026-09-22**：详情面板布局最终定案：三栏 flex + cqw 比例列宽（面板宽 = 一列 = 20cqw，顶替末列），卡片轨道固定、开合时 4↔3 列且前三列轨道不变；此前的悬浮覆盖方案因破坏「三栏格式」被否
- **2026-09-22**：一键启动选型根 package.json + concurrently；端口冲突策略「仅提示不杀」，原因是自动杀进程有误杀风险（如 5173 上是别的项目的 Vite）
- **2026-09-22**：拖拽排序采用全局 sort_order + 「可见子集键重赋值」算法，类目视图与全部工具共用规则；拖动库选 @dnd-kit，原因是网格排序成熟、属交互工具不违反 UI 组件库禁令
- **2026-09-22**：文档体系迁移为模板四件套（CLAUDE.md / 需求 / 技术设计 / 使用文档），原因是统一文档工作流；旧 `docs/requirements.md`、`docs/ux-patterns.md` 保留不用
- **2026-09-22**：主图标定为「深黑圆角方 + 白菱形」，原因是轴对称、元素少、16px 小尺寸下锐利
- **2026-07-31**：EXE 与 ZIP 安装包互斥（设置一个清空另一个），原因是避免同一应用两套安装包混淆；download_url 不参与互斥
- **2026-05-21**：前端目录从 frontend-admin 迁移为 frontend，原因是简化目录结构
- **2026-05-20**：数据库选型 sql.js 而非 better-sqlite3，原因是纯 JS 零编译依赖，Windows 下免 node-gyp
