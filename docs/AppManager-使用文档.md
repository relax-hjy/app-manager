## 快速开始

### 安装 / 启动

```bash
# 首次安装依赖（一键装 backend + frontend）
npm run install:all

# 一键启动前后端（自动预检端口占用）
npm run dev
```

也可以分开启动：`npm run dev:backend`、`npm run dev:frontend`。

### 访问地址
- 本地开发：http://localhost:5173（后端 API：http://localhost:3001）

### 流程 1：首次启动并初始化目录

第一次使用时先把三个系统目录配置好，后续安装包、文档都会归档到这些位置。

**操作步骤：**

1. `npm run install:all && npm run dev` 一键启动 → 浏览器打开 http://localhost:5173
2. 进入【系统设置】页面
3. 填写【安装包管理目录】（base_directory）→ 如 `D:\Installations`
4. 填写【应用安装目录】（install_directory）→ 如 `D:\Softwares`
5. 填写【文档目录】（doc_directory）→ 如 `D:\Documents`
6. 保存后在【应用管理】页面确认数据正常加载

**结果说明：** 系统会把安装包、文档分别归档到这三个目录下，后续流程都依赖它们。

> 注意：目录可以随时修改，但已归档的文件不会自动搬家。

---

### 流程 2：归类并启动一个应用

把本机 EXE 工具登记进系统，之后一键启动。

**操作步骤：**

1. 进入【应用管理】页面 → 左侧【工具类目】栏
2. 点击添加【分类】（如「开发工具」）→ 输入名称确认
3. 点击【添加应用】→ 填写【应用名称】（必填）、选择【分类】（必填）
4. 填写【EXE 路径】、版本、描述 → 保存后在【应用卡片】上确认图标已提取
5. 点击卡片上的【启动】按钮 → 或点开【详情面板】查看完整字段（面板打开时卡片变 3 列、关闭时 4 列，前三列位置不变；启动/编辑/删除按钮固定在面板底部）

**结果说明：** 应用出现在对应类目下，点击【启动】即调用本地 EXE；图标自动从 EXE 提取。

> 注意：类目第一项「全部工具」是所有类目的汇总；删除分类会连同其下应用一起删除。
> 卡片支持【拖拽排序】：按住卡片拖动（位移超过 8px）即可调整顺序，松手自动永久保存；单击仍是打开详情。「全部工具」下拖动只改全局显示顺序，不会改变应用归属类目。

---

### 流程 3：归档应用安装包

为应用设置 EXE/ZIP 安装包或下载地址，便于重装和分发。

**操作步骤：**

1. 进入【安装包管理】页面 → 找到目标应用卡片
2. 点击【设置安装包】→ 选择 EXE 或 ZIP 类型（两者互斥）
3. 通过【文件上传】或【手动输入路径】指定安装包 → 系统自动复制到 `{安装包管理目录}/{应用名}/`
4. 如有官方下载页，填写【下载地址】（可与 EXE/ZIP 共存）
5. 在卡片上点击【下载】按钮验证链接；用【打开目录】按钮检查归档结果

**结果说明：** 安装包集中归档到管理目录，下载地址保留外部获取渠道。

> 注意：EXE 和 ZIP 设置一个会自动清空另一个；下载地址不受此限制。

### 流程 5：自动安装待装应用

用侧栏底部的【自动安装智能体】批量安装「有安装包但未安装」的应用。

**操作步骤：**

1. 进入【安装包管理】页面 → 确认应用已设置 EXE 或 ZIP 安装包
2. （可选）到【系统设置】配置【Claude API Key】启用 LLM 智能决策；不配置则走规则模式
3. 点击侧栏底部【自动安装智能体】卡片上的【一键安装】
4. 展开【任务列表】查看逐应用进度（排队/安装中/成功/失败/需手动）
5. 需要中止时点【取消】（当前应用装完后停止，正在跑的安装器会被终止）

**结果说明：** ZIP 绿色软件自动解压到 `{应用安装目录}\{应用名}\` 并定位主程序；EXE 优先静默安装；静默失败会弹出安装器由你手点（标记「需手动」）。成功后应用自动标记「已安装」并更新路径、重提图标。

> 注意：仅处理「有安装包且未安装」的应用；LLM 模式失败会自动重试 ≤2 次再回退手动；包文件丢失的项会标记「跳过」。

---

### 流程 4：管理与查阅文档

维护知识文档，并关联到具体应用。

**操作步骤：**

1. 进入【文档管理】页面 → 查看【文档列表】
2. 点击【添加文档】→ 填写【文档名称】（必填）、路径、格式、领域、描述
3. 需要批量入库时点击【扫描文档】→ 系统对比磁盘与数据库，列出新增/失效文件
4. 在【搜索框】按名称/描述/分类/格式模糊搜索
5. 点击文档行的【打开文件】或【打开目录】查看内容；在应用【详情面板】中查看关联文档

**结果说明：** 文档可按格式（如「知识总结」）和领域（如「Python」）组织，并可挂到应用下。

> 注意：仅支持 `.md` 和 `.pdf`；文档目录约定 `{文档目录}/{格式}/{领域}/{文件名}`；删除分类前需先清空其下文档。

## 常见问题

**Q：`npm run dev` 报「端口被占用，启动已取消」？**
A：预检发现 3001/5173 已有监听（只提示不杀）。按提示的 `taskkill /PID <pid> /F` 停掉占用进程后重试；PID 可用 `netstat -ano | findstr :3001` 自查。单独启动后端遇占用也会打印同样的友好提示（不再是 EADDRINUSE 堆栈）。

**Q：页面能打开但数据加载失败？**
A：多半是后端没起来或连到了旧进程。先访问 http://localhost:3001/api/health 确认返回 `{"success":true}`，再刷新页面。

**Q：点【启动】没反应？**
A：启动是 fire-and-forget，成功即刻返回。请确认【EXE 路径】在本机真实存在（可用【打开目录】检查所在文件夹）。

**Q：【扫描文档】扫不到我的文件？**
A：仅支持 `.md` 和 `.pdf`，且文件需放在 `{文档目录}/{格式}/{领域}/` 结构下；以 `.` 开头的隐藏文件会被跳过。

**Q：改了图标/标题后浏览器里没变化？**
A：favicon 有强缓存，按 Ctrl+F5 强制刷新或重开标签页。
